== Description ==

Accept USDT on TRON (TRC20), BSC (BEP20) and Ethereum (ERC20) using your own wallets.

Set an address and QR code for each network. The customer picks a network, pays, and
submits the transaction hash with an optional receipt. The payment stays pending until an
admin checks it on the network's block explorer from the View Transaction page.

USDT is treated as 1:1 with USD. Payments in other currencies need currency conversion
turned on for this gateway.
